# Декомпозиция эпика Корзина

## Модуль 1: Экран корзины и список товаров:

#### Верстка основного экрана корзины (est: 10 hours; fact:)
- Создание таба корзины и базового UITableView/UICollectionView
- Верстка ячейки NFT (название, рейтинг, цена, кнопка удаления)
- Реализация нижнего Bottom Tab с итоговой суммой и кнопкой «К оплате»

#### Обработка пустого состояния (est: 4 hours; fact:)

#### Интеграция API корзины (est: 8 hours; fact:)
- Получение списка NFT, добавленных в корзину (GET запрос)
- Обновление состава корзины на сервере (отправка актуального массива ID через PUT/POST запрос)
